2D Payment Gateway API Integration

Connect your booking application, SaaS, or e-commerce platform to ApexPay. You can use either Hosted 2D Checkout (customer is redirected to a pre-built secure page) or Headless 2D Direct Post (seamless server-to-server card authorization with zero OTP challenge).

1

Create a Payment Order

POST /api/v1/orders/create

When a customer selects a booking slot or service on your website, your backend calls this endpoint to generate a payment session.

Node.js / Express JSON Payload 
const axios = require('axios');

async function initiateBookingPayment(booking) {
  const response = await axios.post('http://localhost:5050/api/v1/orders/create', {
    amount: booking.fee, // e.g. 1500
    currency: 'INR',
    bookingId: booking.id, // e.g. 'BK_LAW_74921'
    customer: {
      name: booking.clientName,
      email: booking.clientEmail,
      phone: booking.clientPhone
    },
    notes: 'Consultation with Advocate Vikram',
    returnUrl: 'https://yoursite.com/booking/verify'
  }, {
    headers: {
      'Content-Type': 'application/json',
      'X-Api-Key': 'pk_live_apex_9381lawconnect_pub'
    }
  });

  // Redirect client to checkoutUrl
  return response.data.checkoutUrl;
}
2

Direct 2D Card Charge (Zero OTP Redirect)

POST /api/v1/charge/direct-2d

If you want full custom UI on your booking page, submit the card details directly to this endpoint. The gateway immediately returns authorization status without 3DS OTP interruption.

cURL Request 
curl -X POST http://localhost:5050/api/v1/charge/direct-2d \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: pk_live_apex_9381lawconnect_pub" \
  -d '{
    "amount": 1500,
    "currency": "INR",
    "bookingId": "BK_LAW_74921",
    "paymentMethod": "card",
    "cardNumber": "4111111111111111",
    "cardExpiry": "12/28",
    "cardCvv": "892",
    "cardHolderName": "Pankaj Sharma"
  }'

Handling Real-time Webhooks

Webhook Receiver

ApexPay fires an HTTP POST to your configured Webhook URL with HMAC-SHA256 signature in the X-Gateway-Signature header.

Node.js Webhook Receiver & Verification 
const crypto = require('crypto');

app.post('/api/webhook', (req, res) => {
  const signature = req.headers['x-gateway-signature'];
  const timestamp = req.headers['x-gateway-timestamp'];
  const secret = process.env.GATEWAY_SECRET_KEY;

  // Verify HMAC-SHA256 signature
  const expectedSig = crypto
    .createHmac('sha256', secret)
    .update(`${timestamp}.${JSON.stringify(req.body)}`)
    .digest('hex');

  if (signature !== expectedSig) {
    return res.status(401).send('Invalid signature');
  }

  const { event, data } = req.body;
  if (event === 'payment.captured') {
    // Confirm booking in your database!
    await markBookingPaid(data.bookingId, data.transactionId);
  }

  res.status(200).json({ received: true });
});
